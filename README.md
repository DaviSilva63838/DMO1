# Projeto de Exercícios em Kotlin

Projeto desenvolvido como parte do curso de Desenvolvimento Mobile no IFSP.

## Sobre o projeto

Este projeto foi desenvolvido para praticar os conceitos básicos da linguagem Kotlin.

## Objetivo

O objetivo do projeto é aprender e praticar:

Variáveis
Entrada de dados
Saída de dados
Condicionais
Operações matemáticas
Strings
Cálculo de média

## Tecnologias utilizadas
Kotlin
IntelliJ IDEA
Git e GitHub

## Exercícios
1. Manipulação de variáveis

O programa utiliza var e val para armazenar valores.

2. Idade

O usuário digita sua idade e o programa informa qual será sua idade no próximo ano.

3. Palavra

O programa recebe uma palavra e mostra ela em maiúscula e minúscula.

4. Soma

O programa recebe dois números e calcula a soma entre eles.

5. Par ou ímpar

O programa verifica se um número é par ou ímpar.

6. Média

O programa recebe três notas e calcula a média do aluno.

Média	Situação
6 ou mais	= Aprovado
4 até 5,9	= Recuperação
Menor que 4	= Reprovado

## Como executar
Abra o projeto no IntelliJ IDEA.
Abra o arquivo Main.kt.
Clique em Run.
Digite os valores solicitados no console.
